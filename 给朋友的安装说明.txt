  视频抓取（VideoGrab）  ·  安装说明（发给朋友看的）
════════════════════════════════════════════════════════════

你收到的是：一个叫 VideoGrab-unsigned.ipa 的文件（大约 11 MB）。
你的手机：iOS 18 —— 支持，可以装。

⚠️ 先说清楚一件事（不然你会卡在第一步）：

   这个包**没有签名**，iOS 不会直接装它。要用**你自己的 Apple ID**
   给它"盖个章"，手机才肯装。下面这套做法是**免费**的，只要一台电脑 + 十几分钟。

   为什么不能直接发个能装的给你：免费签名是绑在"你自己的 Apple ID +
   你这台手机"上的，别人替你签不了。要么你自己签（下面这么走），
   要么对方用付费开发者账号把你的手机加进名单（那要花钱）。


────────────────────────────────────────────────────────────
第一步  电脑上装 AltServer
────────────────────────────────────────────────────────────

 1. 电脑上打开浏览器，进 altstore.io （**只认这个官网**，别用各种"下载站"）
 2. 下载 Windows 版 AltServer，双击装好
 3. 如果它提示要装 iCloud 和 iTunes（Windows 版可能需要），按提示装上就行
    —— 这两个是让电脑能认到你 iPhone 用的，不用登录


────────────────────────────────────────────────────────────
第二步  把 AltStore 装到你手机
────────────────────────────────────────────────────────────

 1. iPhone 用数据线连电脑（也可以两个连同一个 Wi-Fi）
 2. 手机屏幕上如果弹"要信任此电脑吗" → 点信任
 3. 电脑右下角托盘里找到 AltServer 的小图标 → 右键 → Install AltStore → 选你的 iPhone
 4. 它会让你输入 Apple ID：
      ★ 用**自己的** Apple ID 就行，**免费账号足够**
      ★ 建议用一个小号（不常用的）。这个密码是用来去苹果服务器换签名证书的
 5. 装完，手机上打开：设置 → 通用 → VPN 与设备管理 → 找到你那串 Apple ID → 点「信任」


────────────────────────────────────────────────────────────
第三步  把这个 ipa 装进去
────────────────────────────────────────────────────────────

 1. 先把 VideoGrab-unsigned.ipa 存到手机上（微信 / QQ / 网盘 / AirDrop 传给自己
    都行；如果微信发不过去，把 ipa 压成 zip 再发，到了手机再解压）
 2. 打开手机上的 AltStore → 下面选 My Apps → 左上角那个「+」
 3. 选刚才那个 ipa → 它会自动签名并安装，等它跑完
 4. 装好后先别急着开，**再去一次**：设置 → 通用 → VPN 与设备管理 → 点信任
 5. 打开「视频抓取」，能用了


────────────────────────────────────────────────────────────
几件必须知道的事
────────────────────────────────────────────────────────────

 · **7 天会过期**：免费账号签的 App 只能用 7 天。
   电脑跟手机在同一个 Wi-Fi 时 AltStore 会**自动帮你续签**，你不用管。
   真过期了打不开 → 开一下 AltStore，或者插一下电脑，就恢复了。
 · **同时最多 3 个**这种自签 App —— 多的会挤掉，注意别签太多。
 · 想删掉重装：长按图标删掉，再从第三步来一遍。


────────────────────────────────────────────────────────────
不想用电脑？
────────────────────────────────────────────────────────────

 有个叫 SideStore 的东西（跟 AltStore 是同一个开源项目），装好之后
 **不用插电脑**就能续签 —— 但**第一次仍然需要一台电脑做一次配对**。
 要的话说一声，我把那份步骤也写给你。
