v1.0.13 修了什么（针对你上一轮的两个反馈）
────────────────────────────────────────────────────────────

【点播放还是白屏】这次找到了真正的根因
  v1.0.12 修的是「播放器被反复重建」，但那个不是主因。
  真正的根因在弹窗本身：
    旧代码是 .sheet(isPresented: 布尔) { if let u = 地址 { 播放器 } }
    SwiftUI 在弹出的一瞬间就会执行花括号里的内容，而那时「地址」
    这个状态可能还没写进去 → 内容是空视图 → 纯白一屏。
    （你截图里连我们画的黑底、关闭按钮、转圈都没有 —— 因为
     内容根本就是空的，跟播放器没关系）
  修法：把「地址」本身当成弹窗的触发源（.sheet(item:)），
  有地址才有弹窗，「弹出了但内容是空的」从结构上不可能再发生。

【转 MP4 失败：writer 长时间不接收数据】根因已查实
  上一版的过程记录其实是个好消息：TS 解析、视频轨音频轨的
  提取全部跑通了，卡在最后写 MP4 那一步。
  查证（Apple 文档原话）：一个 writer 带多条轨道时，它按时间戳
  交错写入；某条轨道不「就绪」时不能给它塞数据。
  旧代码先把视频全喂完再喂音频 —— 视频很快不就绪（它在等同一
  时间段的音频），音频又排在后面没机会喂 → 两边互相等，卡死。
  修法：改成按时间戳归并 —— 每次挑时间更早的那路喂，
  一路不就绪就先喂另一路，绝不死等。

────────────────────────────────────────────────────────────
v1.0.12 已改的（需求调整 + 三个问题）
────────────────────────────────────────────────────────────

【需求调整】视频留在程序内，不下就不出去
  下载完自动转 MP4，要不要保存由你点按钮决定：
    「存相册」—— 存进系统相册（第一次会问权限）
    「存文件夹」—— 系统存储面板，你选位置，复制一份过去
    不点 —— 它就留在程序里，不会跑到外面去
  存储位置在 App 私有目录，「文件」App 看不到（之前放在
  Documents 且开了文件共享，等于还没选就已经在外面了）。
  转 MP4 成功后会把 .ts 和临时清单删掉（省一半空间）。

【问题1 重启后下载记录丢失】已修
  记录写进 records.json：每次状态变化、以及切后台前各存一次。
  重启后记录还在，文件还在的就能继续播、继续存；
  上次没下完的会标成「中断」。

【问题2 嗅探结果分不清新旧】已修
  每条都标「几点几分几秒 · 刚刚/N分钟前 · 出现 N 次」，
  90 秒内出现的带红色「新」标记，同类里最近嗅到的排最前面。

────────────────────────────────────────────────────────────
怎么用
────────────────────────────────────────────────────────────

1. 地址栏输入视频站地址，进去
2. ★ 点一下播放，让视频真的加载几秒（地址是播放时才产生的）
3. 长按视频画面，或点右下角圆圈 → 弹出嗅探结果
4. 按嗅探时间挑最新那条标着 M3U8 的 → 开始下载
5. 下完自动转成 MP4。要保存就点「存相册」或「存文件夹」
   —— 不点的话它就留在程序里，不会跑到外面去
6. 播放直接点「播放」按钮，在程序里看

────────────────────────────────────────────────────────────
已知限制
────────────────────────────────────────────────────────────

· 转 MP4 是「只换容器、不重新编码」，很快、画质无损、体积几乎不变。
· 转不成时会保留 .ts 原文件，可以用「存文件夹」导出后用 VLC 打开，
  失败的具体原因会写在「过程记录」里。
· 存相册第一次会弹权限询问，同意一次即可。
· DRM 加密的付费影片拿不到，任何工具都做不到。
· 有些站的地址是脚本算的、或走了第三方解析，可能嗅不到 ——
  换个线路、或让视频多播一会儿再刷一次。
