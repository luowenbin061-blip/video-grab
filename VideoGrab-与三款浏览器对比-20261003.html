VideoGrab 与「鲨鱼 / 李白 / 亚瑟」对比

三款对手的数据全部取自 App Store 官方描述（Apple 官方接口，2026-10-03 抓取）＋ 版本号/体积/更新日期； VideoGrab 一侧是逐项对着源码核实的结果，不是凭印象。

先给结论（三条）

  1. 三款里只有「亚瑟」跟咱们是同一条赛道（资源嗅探＋下载＋m3u8 合并）。 另外两款根本不下载 —— 鲨鱼和李白的主语都是「播放器」，它们做的是在线看。
  2. 在「下载 ＋ 后处理」这条线上，咱们比它们都厚： 局域网共享给电脑、零损失合并、画质压缩、下载队列、回收站 —— 这四样三款一个都没有。
  3. 真正的短板是「播放体验」：最扎眼的是倍速播放和投屏，三款全有、咱们一个都没有。 而这两项恰恰是最便宜的 —— 都是系统自带 API。
还有一条容易忽略、但很重要的事实 那三款都是 App Store 上架的应用 → 按苹果政策，它们也必须在 WKWebView 上跑， 跟咱们是同一个引擎、同一套限制。所以：它们做得到的功能，咱们原则上都做得到， 不需要为了「追上它们」去换引擎。

四、各家的「独家本领」

鲨鱼 —— 主打「看」

  • 最高 16 倍速播放（三款里最猛）、AirPlay / DLNA 投屏、一键锁屏、一键静音、后台播放
  • 分屏浏览（同一页开两个窗口，压着调整布局）—— 只此一家
  • 小说阅读模式（自动预加载、章节收藏、双击翻页）＋ 电子书（翻页效果、章节目录）
  • 页面任意位置滑动返回、扫码、文件解压

李白 —— 主打「工具」

  • 语音文本翻译 ＋ 朗读（明确说面向出国旅游）
  • OCR 拍照取字
  • 用户自定义脚本（油猴类）、iCloud 书签同步
  • 视频悬浮播放
  • 注意：最近一次更新停在 2026-05-07，已经 5 个月没动

亚瑟 —— 跟咱们最像的那个

  • 资源嗅探、加密 m3u8、文件下载、导出、投屏合并
  • 开发者工具（移动端少见）、油猴脚本
  • 隐私加密相册、小游戏存档
  • 主打「体积小、内存低」—— 但实际包体 104.6 MB，跟另两款一个量级

咱们 —— 主打「下载 ＋ 后处理」

  • 局域网共享给电脑：手机里下好的片子，电脑浏览器直接打开取走（自带 HTTP 服务 ＋ WebDAV）—— 三款都没有
  • 零损失合并（规格一样的片段直接搬、不重编码）＋ 压画质省空间 —— 三款都没有
  • 下载队列（同时下载数 1/3/5/不限）＋ 回收站（删错能找回）—— 三款都没有
  • 边下边播、断点续传、PiP 保活（下载时后台不被杀）
  • 导出 PDF、导入书签、导入本地视频、备份数据
  • 免费、无广告、无内购、无账号

五、差距清单与建议

P0 —— 建议补，成本极低（都是系统自带 API）
  • 倍速播放：三款全有、咱们没有。播放器加一个速度档位（AVPlayer.rate，0.5× / 1× / 1.5× / 2×）—— 改动几十行
  • 投屏 AirPlay：三款全有、咱们没有。系统自带一个投屏按钮控件（AVRoutePickerView），接上去就行
  • 长按快进 / 快退：鲨鱼有，看片时很实用，手势加一下即可
这三条加起来就是一个「播放体验」小版本，风险低、每天都能感觉到。
P1 —— 值得做，成本中等
  • 小窗 / 悬浮播放：咱们已经有画中画（现在主要当"下载保活"用），扩成「播放时也能小窗」并不远
  • 夜间模式：往网页里注入一段变暗的 CSS 即可（跟现有注入通道是同一套）
P2 —— 看你要不要（成本更高，收益看个人习惯）
  • 阅读模式：咱们已有「导出 PDF」的正文提取底子，做起来比另两款从零做要容易
  • 用户脚本（油猴）：亚瑟／李白有。技术上可行，但等于要维护一个脚本运行环境
  • 网络层广告拦截：这是唯一能「从根上」拦广告的路（拦请求，而不是事后清浮层）—— 但需要规则库，之前评估过成本
建议不要补（对「自用」没有意义）
  • 账号体系、内购、iCloud 同步 —— 那是人家的商业模式，你不需要
  • 翻译 / OCR / 电子书 / 扫码 —— 那是「通用浏览器引流功能」，跟你「下片」的目标不搭
  • 为了「追上它们」去换浏览器引擎 —— 没必要：它们也跑在 WKWebView 上，同一个引擎能做到的事，你现在这套也能做
一句话总结 三款里真正跟你同类的是亚瑟；而在「下载 ＋ 后处理」这条线上，你已经比它更厚 （局域网共享、合并压缩、下载队列、回收站，它一样没有）。 你真正落后的是播放体验 —— 倍速和投屏这两块三款全有，而它们恰恰是最便宜就能补上的。
